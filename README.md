# Nikhil Mishra — IT Portfolio

Personal portfolio website built to showcase my IT career, skills, certifications, and professional achievements.

🌐 **Live Site:** [codewithnyk.github.io](https://codewithnyk.github.io)

---

## About

This portfolio was designed to give hiring managers and recruiters a clear picture of my background as an IT Support Engineer with 5+ years of experience across India and Germany. It covers my work with ServiceNow, Azure AD, Python automation, and ITSM — along with certifications and awards.

---

## Sections

- **Hero** — Introduction with animated typewriter role titles
- **About** — Background, skill highlights, and contact links
- **Skills** — Tech stack displayed as a visual pipeline (ITSM, Cloud, Infrastructure, Scripting, Monitoring)
- **Experience** — Full work history with company logos, employment type, and clickable company links
- **Certifications** — Professional certifications with PDF links and verification
- **Awards** — Hack4Good 2025 (1st Place) and Customer Satisfaction Award (Capgemini)
- **Education** — MSc Data Science, FAU Erlangen-Nürnberg + BTech CS

---

## Tech

Built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

- Scroll-driven reveal animations
- Typewriter effect
- Responsive design (mobile, tablet, desktop)
- Canvas background animation
